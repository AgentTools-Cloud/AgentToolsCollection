Scope & limits

Methodology

Every number is a count over the agent-tools.cloud index at the time shown above, recomputed once a day after our probes run. It is not a census of the whole ecosystem: listings no public source has shown us are missing, and private deployments are invisible to us.

Funnel. Reachable means the last probe got a valid answer. Verified means a valid 402 challenge for x402, a full MCP initialize plus tools/list, or an A2A JSON-RPC reply on the declared interface.

Sources. Duplicates across sources are merged by endpoint; each source a listing came from is kept.

Protocols. Versions are what the listing reports or declares; we do not infer them from behaviour. A2A signatures are verified against the key the card points to on its own site.

Readiness. Criteria and weights are on the About page. Points earned from live probes decay after 30 days without a fresh one.

Reliability. One probe per listing per day from one server; latency includes our network path and is not a provider SLA.

x402. Price per API is the lowest amount its payment terms ask for one call, in USD (USDC read at par). The x402 version is counted only where our resource probe recorded it. Settlement network falls back to the chains a listing declares when the challenge does not name one.

Access. Declared by the listing or its card; not tested with credentials.

Safety. Pattern rules over tool metadata only; no code is executed.

Topics. Whole-word match of a fixed word list on name and description. Listings whose text names more than five topics (gateway catalogues) are left out{% if snap.topics.skipped_catalogue %}: {% for k, n in snap.topics.skipped_catalogue.items() %}{{ n|num }} {{ kind_label[k] }}{{ ', ' if not loop.last }}{% endfor %}{% endif %}.

Growth. Earliest first-seen date across a listing's sources.

Adoption. GitHub stars and last push from the GitHub REST API for the repository a listing links as its source; npm downloads over 30 days from the npm downloads API for packages published on npm; site rank from the Tranco research list (registrable domain). Several listings can share one repository. These are attention signals, not measures of quality, and are not used for ranking.
