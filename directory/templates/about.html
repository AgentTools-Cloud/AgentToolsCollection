关于 agent-tools.cloud

agent-tools.cloud 是一个 x402 付费 API 与 MCP 服务的目录站, 面向中文 / 亚太开发者,强调 agent 友好的发现接口。

x402 是 Coinbase 主推的 HTTP 402 微支付协议,允许 AI agent 用 USDC 在链上自动结算 API 调用费。 本站收录全网公开的 x402 服务,每 6 小时刷新一次健康状态。

数据来源

  • awesome-x402
  • x402scan
  • Coinbase CDP Bazaar
  • 人工提交(/submit)

给 Agent 用

每个 agent 可以直接 GET /api/v1/search?q=<query> 来发现合适的 x402 服务,并使用 x402-fetch 或 x402-axios 自动处理 402 支付流程。

Agent 发现入口:/.well-known/agent-tools.json
