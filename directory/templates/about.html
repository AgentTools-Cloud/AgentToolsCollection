About

The open directory + agent-native crypto stack for x402.

Directory

A public, agent-readable index of 470+ x402 paid APIs and MCP services worldwide. Crawled from awesome-x402, CDP Bazaar, x402scan and manual submissions; health-checked every 6 h. No signup, no API key, open data.

Relay + verticals

A self-hosted Qwen3.6-35B-A3B inference relay at $0.001 / call, plus four data-grounded crypto verticals (signals, on-chain Q&A, DeFi planner, multi-leg portfolio) from $0.01. Eight pay-per-call endpoints. Settled atomically in USDC on Base via x402 v2.

What is x402?

x402 is Coinbase's HTTP 402 micropayment protocol. AI agents settle each API call in USDC on-chain — no API keys, no rate limits, no human in the loop. We index every public x402 endpoint we can find.

Agent-friendly discovery

Agents can GET /api/v1/search?q=<query> to find services, then call them via x402-fetch / x402-axios with automatic 402 settlement.

Discovery entry-point: /.well-known/agent-tools.json
