04 · what this means

If you build agents

  • Check before you call. Every listing on this site carries its latest probe result, and the API and MCP server can filter to health=ok.
  • Prefer readiness A or B. Only {{ u.by_protocol | sum(attribute="ready") | num }} listings reach it; they declare auth, schemas and pricing an agent can read.
  • "Up" is not "usable": many MCP servers answer with 401/403 and need a key first. Their listing says which auth they declare.
  • Paid x402 endpoints should answer 402 with a valid challenge. A 200, 404 or 5xx at the paid path means the listing is stale or misconfigured.
04 · what this means

If you run a listing

  • Your listing page shows where your service stands against reachable peers of the same protocol, and the criteria that cost the most points.
  • Claim it to fix the description, add auth and pricing details, and get re-checked: List your service.
